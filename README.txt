CHOWDECK UI/UX PROTOTYPE

This is a multi-page frontend prototype:
index.html       Splash + homepage
explore.html     Food discovery and category filters
details.html     Meal details
cart.html        Cart and checkout demo
orders.html      Orders screen
profile.html     Profile screen
style.css        Shared styling
data.js          Food data
app.js           Shared interactions
assets/hero-video.mp4  Uploaded hero video
assets/chowdeck-logo.svg  Prototype logo asset

Open index.html or deploy the whole folder to Netlify.
Food photos are loaded from Unsplash and require internet access.
The project is a non-official UI/UX prototype and is not affiliated with Chowdeck.
